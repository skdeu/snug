# Snug v1.3 Glass Look and UI/UX Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking. Do not start until SK approves this revised plan.

**Goal:** Give Snug an in-app glass look (translucent chrome over a painted ambient backdrop) in the Graphite and sage palette, with a token layer, clear control states, a designed reader and editor, and dismissable notices.

**Architecture:** The window stays opaque. Snug paints a static ambient backdrop on its root. The chrome (tab strip, toolbar, sidebar, find bar, notices) sits on `backdrop-filter` glass, with a solid fallback in `@supports`. The reader and editor keep near-opaque grounds. Colours come from CSS tokens in `src/styles/tokens.css`. Icons, the toolbar and notices move into small components so they can be tested.

**Tech Stack:** Tauri 2.12.7 (Rust, WebView2), React 19, TypeScript, Vitest, CodeMirror 6, markdown-it.

**Spec:** [docs/superpowers/specs/2026-11-20-snug-v1.3-design.md](../specs/2026-11-20-snug-v1.3-design.md)

**Revised 2026-11-20:** in-app glass and Graphite replace the Windows-glass tasks of the first draft. Those tasks (window transparency, Mica, runtime effect control) are removed.

**Starts from:** the uncommitted v1.2 working tree on `master`. Nothing here commits, tags or installs until SK asks.

## Global Constraints

- Glass is CSS only (`backdrop-filter`). The window stays opaque. No window effects and no transparent window.
- Graphite and sage is the only palette in the app. Settings and session file formats do not change.
- Keep these class names: `.snug-reader`, `.snug-tab`, `.snug-tabbar`, `.snug-error`, `theme-dark`, `theme-light`.
- Tab drag, tear-off, shortcuts and the quit prompt keep their v1.2 behaviour.
- Test baselines: Vitest 66 at v1.2, `tsc --noEmit` clean, cargo test as in v1.2. New tests are added; none are removed.
- New dependency: `@codemirror/language`, added explicitly. No icon package.
- Version `1.3.0` in `package.json`, `package-lock.json`, `src-tauri/Cargo.toml`, `src-tauri/Cargo.lock`, `src-tauri/tauri.conf.json`.

## Review Focus

1. Chrome text keeps 4.5:1 over the glass composite, and muted text never sits on the active tab. Test: Task 1 composite tests and the active-tab rule test.
2. A browser without `backdrop-filter` gets a solid chrome, not an unreadable translucent bar. Test: Task 2 `@supports` test.
3. The reader and the editor stay near-opaque, so long reading stays comfortable. Test: Task 2 test that `backdrop-filter` is absent from reader and editor CSS, and Task 1 token test on `--reader-bg`.
4. Blur is limited to the fixed chrome, so resizing stays smooth. Test: Task 2 selector test; manual resize check in Task 6.
5. Tab drag and tear-off still work with the new markup. Test: existing TabStrip pointer tests kept; manual drag check in Task 6.

## Risks

- `backdrop-filter` cost while resizing: blur only the fixed chrome.
- The canvas floats the window in its artboard, so the real window shows less blob. Check the real app before settling the blob strength.
- The solid fallback is checked by the CSS test and by reading, not by a live run.
