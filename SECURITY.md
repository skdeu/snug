# Security policy

## Supported versions

Only the latest release of Snug receives security fixes.

## Reporting a vulnerability

Please do not open a public issue for a security problem.

Report it privately: open the **Security** tab of this repository and choose **Report a vulnerability**. This uses GitHub's private vulnerability reporting, so only the maintainer can see the report.

Please include:

- the Snug version and your Windows version;
- the steps that reproduce the problem;
- what you expected, what happened, and the impact you think it has.

The maintainer will reply as soon as they can, and will keep you informed while the problem is fixed. Once a fix is released, the report can be published with credit, if you want it.

## Scope

Snug reads and writes local files and opens web links in your browser. Problems such as reading or writing files outside the folders a user chose, running code from a note, or sending data over the network are in scope.
